# 💻 Clone da Página do MacBook Air

Este projeto é uma recriação fiel da landing page oficial do **MacBook Air** da Apple, desenvolvido com **HTML5**, **CSS3** e **JavaScript Vanilla**. Criado durante a **Start Week**, ele tem como objetivo praticar e demonstrar habilidades de front-end ao replicar um layout sofisticado, responsivo e com interações visuais refinadas — inspirado no padrão de qualidade da Apple.

> ✨ Uma excelente adição ao portfólio para quem deseja mostrar atenção a detalhes, domínio de estruturação web e foco na experiência do usuário.

## 🚀 Tecnologias Utilizadas

- **HTML5**
- **CSS3** (com responsividade)
- **JavaScript Vanilla** (sem frameworks)
- **Skeleton CSS** (para estrutura básica)

---

## 🛠 Funcionalidades

- Estrutura de código organizada e semântica.
- Layout responsivo, adaptado para diferentes dispositivos.
- Interações simples, como troca de cor de produto (simulando seleção de modelo).
- Fidelidade visual ao design original, com atenção a espaçamentos, tipografia e transições.
